# NLP Emotion Classification

## About the Project
This project uses Natural Language Processing (NLP) and Machine Learning to classify emotions from text.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- NLP

## Emotion Categories
- Sadness
- Anger
- Love
- Surprise
- Fear
- Joy

## Algorithms Used
- Support Vector Machine (SVM)
- Random Forest
- Logistic Regression
- Multinomial Naive Bayes

## Results
SVM achieved the highest accuracy of **89.22%**.

## Conclusion
This project demonstrates multiclass emotion classification using machine learning techniques.
